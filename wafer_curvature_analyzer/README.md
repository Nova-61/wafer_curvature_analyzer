# Анализатор кривизны подложки

Программа для расчёта механического напряжения плёнки по изгибу подложки
(wafer bow), с раздельными формулами аппроксимации для линейного (2D) и
полного поверхностного (3D) скана, и с расчётом напряжения в каждой точке.
Работает одинаково на **Windows** и **Linux Mint**.

## Рабочий процесс

1. **Добавить файл(ы) в «Подложка (до напыления)»** и/или **«Плёнка (после напыления)»**.
   Можно добавить несколько файлов в одну группу — их высоты автоматически
   усредняются поточечно. Файл можно убрать кнопкой «Убрать» (выделите его в списке).
2. Как только файлы добавлены — **всё пересчитывается автоматически**:
   аппроксимация, радиус(ы) кривизны, отклонение (в % — по ТЗ: (max−min)·100).
   Результаты сразу видны в панели «РЕЗУЛЬТАТЫ».
3. Кнопка **«Аппроксимация»** — включает/выключает отображение аппроксимирующей
   кривой (2D) или поверхности (3D) на графике (расчёт уже готов, кнопка только
   рисует).
4. Кнопка **«Рассчитать напряжение»** — по введённым E, ν, толщине подложки и
   плёнки считает напряжение по формуле Стоуни. Заодно готовит **карту
   напряжения в каждой точке**.
5. Кнопка **«Карта напряжения (в каждой точке)»** — показывает на графике
   локальное напряжение (цветом — в 3D-режиме, кривой σ(x) — в 2D).
6. **«Экспорт результатов»** — сохраняет всё в один CSV-файл с несколькими
   таблицами (сводка, данные до/после, карта напряжения).

## Почему формулы для 2D и 3D разные

- **2D** (линейный скан, `y(mm)` не меняется):
  аппроксимация `y = b·x + a·x² + c`, радиус кривизны `R = 1/(2|a|)`.
- **3D** (полный скан поверхности, координаты `x(mm)`/`y(mm)` реально меняются,
  как в примере `349p_FOCUS_W_NO_VAC_HEXAGON.csv`):
  аппроксимация `z = z0 + a·x + b·y + c·x² + d·y²`,
  радиусы кривизны `Rx = 1/(2|c|)`, `Ry = 1/(2|d|)` — по осям X и Y отдельно.

Если один из этапов (до/после) измерен только линией (мало точек, `y=0`), а
другой — полным сканом, то для линейного скана используется физически
обоснованное **допущение изотропности** (кривизна одинакова во всех
направлениях), поэтому `Rx = Ry = R`, вычисленный из 2D-аппроксимации по
радиусу `r = √(x²+y²)`. Это именно тот сценарий, когда, например, кремний
измерен по одной линии (`Si_no_vac_1.csv`), а вольфрам — полным гексагональным
сканом (`349p_FOCUS_W_NO_VAC_HEXAGON.csv`).

## Напряжение по Стоуни

```
σ = E_s · t_s² / (6 · (1 − ν_s) · t_f) · (1/R_после − 1/R_до)
```

Для 3D считается отдельно **σx** (через Rx) и **σy** (через Ry), итоговое
значение — их среднее арифметическое, как указано в ТЗ.

### Напряжение в каждой точке

В дополнение к общему (глобальному) напряжению программа считает напряжение
**в каждой точке** сетки «после напыления»: вместо одного глобального радиуса
кривизны для всей кривой/поверхности используется **локальная кривизна**
(через сглаживающий сплайн) в окрестности каждой точки. Для линейного скана —
кривая σ(x), для поверхности — цветовая карта σ(x,y) с шкалой в МПа.

## Формат входных CSV

Программа сама распознаёт файлы вида:

```
Company:,Eoptics,RcpName:,...
Type:,Blanket,Wafer size:,8 inch,...
Process start time,...,Process end time,...
No,x(mm),y(mm),Intensity,Height(mm),MSE,GOF,...
1,0,0,12030.8,18.7950,...
...
Min,,,,,...
Max,,,,,...
```

— сама находит строку заголовка, отбрасывает служебный блок `Min/Max/Average`
снизу, использует колонку `Height(mm)`. Если `y(mm)` не меняется в пределах
файла — это 2D (линейный) скан, если меняется — 3D (поверхностный).

## Установка

### Windows
Для запуска из исходного кода установите Python 3.12+ с
[python.org](https://www.python.org/downloads/) (отметьте "Add Python to PATH"),
затем выполните в папке программы:
   ```
   pip install -r requirements.txt
   ```

Для установки как обычного приложения Windows скачайте и запустите
`WaferCurvatureAnalyzerSetup.exe`. Установщик создаст ярлык в меню «Пуск»;
удалить программу можно через «Параметры Windows → Приложения» или
«Установка и удаление программ».

Чтобы собрать установщик самостоятельно, установите Python 3.12+ и
[Inno Setup 6 или 7](https://jrsoftware.org/isinfo.php), затем запустите
`scripts\build_win.bat`. Готовый установщик появится в папке `dist`.

### Linux Mint
```bash
sudo apt install python3 python3-pip python3-pyqt5
pip3 install -r requirements.txt
```

## Запуск

**Windows:** `scripts\run_win.bat` (двойной клик).

**Linux Mint:**
```bash
chmod +x scripts/run_linux.sh
./scripts/run_linux.sh
```

Либо напрямую: `python main.py` (Windows) / `python3 main.py` (Linux).

Окно свободно меняет размер — просто потяните за край окна мышью.
